Settings

Any OpenAI-compatible /chat/completions endpoint: OpenAI, OpenRouter, Ollama (http://localhost:11434/v1), vLLM, LM Studio (http://localhost:1234/v1), llama.cpp llama-server (http://localhost:8081/v1: its default port 8080 is iRoof.top's, so start it with llama-server --port 8081). Empty uses OPENAI_BASE_URL from the server environment.
Model id at that endpoint. It must support tool calling. For Describe in the media library it must also accept images. Empty uses OPENAI_MODEL.
Stored on this server only. Leave empty to keep the saved key, type - to clear it. Without a saved key OPENAI_API_KEY is used.
Randomness, 0–2. Empty keeps the provider default. 0.7–1.0 usually sounds the most natural.
How much of the chat (in characters, ≈ 3–4 per token) is replayed to the model. When it is exceeded, the oldest part is folded into a short memory summary once, keeping the prompt cache stable. Older messages stay searchable.
Used to describe photos and stickers and to transcribe voice messages (yours and the export's), so the persona knows what they show or say. It must accept images and audio, e.g. google/gemini-3.5-flash-lite on OpenRouter. Empty uses OPENAI_MEDIA_MODEL, then Model.
How many LLM rounds one answer may take (e.g. search history, then call an MCP tool, then reply). Higher allows more tool use but costs more.
Telegram
Share links can post visitor messages to a Telegram group. There you press Reply and answer yourself, or let the AI answer when a countdown ends. Shared bot needs no setup: the iroof.top bot relays the messages for you, so they pass through iroof.top. Own bot: create one with @BotFather and paste its token, and messages go straight between this app and Telegram. A bot token works in one app at a time.
Common mcpServers JSON: HTTP url (+ headers) or stdio command/args/env. Protocol revisions 2024-11-05 → 2026-07-28. Tools such as Giphy let the persona find and send new GIFs.
Example: {"giphy": {"command": "npx", "args": ["-y", "mcp-server-giphy"], "env": {"GIPHY_API_KEY": "…"}}}

Share links

Send a link so other people can talk to this persona, for example a friend who wants to see how well the AI writes in your style, or talks to a copy of themselves. Visitors see only the chat: no settings, notes, media descriptions, LLM prompt or other chats. By default every visitor gets an own conversation that starts after the end of the export, and you can read them all here. A PIN is checked on the server, and wrong guesses lock the link for that visitor first, then for everyone, for longer and longer. Each persona answer costs tokens on your API key, so keep the limits.
